## The line

> At the airport they asked if I'd packed my own bag. My mother shouted 'Not properly' from three people back.

108 characters — within the 1–140 character gate.

## How it works

`main.ts` writes the single funny line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt` when set). Run it with:

```sh
node main.ts
```
